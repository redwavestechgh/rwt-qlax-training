Chapter 02

SPSS Orientation

You already have SPSS — here's how to use it effectively. SPSS has been the gold standard for statistical analysis in social sciences and health research for decades. Let's get you comfortable with it fast.

Data View vs Variable View ▶

When you open a dataset in SPSS, you'll see two tabs at the bottom of the screen:

  • Data View — this is your spreadsheet. Rows are cases (respondents, observations). Columns are variables. The values in cells are the actual data points you collected.
  • Variable View — this is where you define each column. Here you set the variable name, data type, label (a longer description), value labels (e.g., 1 = Male, 2 = Female), and measurement level (nominal, ordinal, scale).
Tip

Always set up Variable View properly before collecting or entering data. Clean variable definitions make analysis dramatically easier.

The Analyze Menu ▶

The Analyze menu is where SPSS's statistical power lives. The key submenus you'll use in this bootcamp:

  • Descriptive Statistics → Frequencies, Descriptives, Explore, Crosstabs
  • Compare Means → Independent Samples T-Test, One-Way ANOVA
  • Correlate → Bivariate (Pearson, Spearman)
  • Regression → Linear, Binary Logistic
  • Nonparametric Tests → Chi-Square, Mann-Whitney

Each submenu opens a dialog box where you drag variables into the appropriate fields and click OK.

Importing a CSV into SPSS ▶
  1. Go to File → Open → Data
  2. In the file dialog, change the Files of type dropdown to CSV (*.csv)
  3. Browse to your CSV file and click Open
  4. The Text Import Wizard will open — follow these steps:
    • Step 1: Select "Delimited" and confirm your file has variable names at the top
    • Step 2: Set delimiter to "Comma"
    • Step 3: Review the data preview — confirm columns align correctly
    • Step 4: Set variable formats (numeric vs string)
    • Step 5: Click Finish
  5. Save as .sav format immediately: File → Save As
Tip

Always save a .sav copy of your imported data. The .sav format preserves all your Variable View definitions — column types, labels, and value codes.

Running Descriptive Statistics ▶
  1. Go to Analyze → Descriptive Statistics → Descriptives
  2. In the dialog box, drag the numeric variables you want to analyze into the Variables list on the right
  3. Click Options to choose which statistics to include: Mean, Std. Deviation, Min, Max, Variance, Skewness, Kurtosis
  4. Click Continue, then OK
  5. The output will appear in the Output Viewer window

For categorical variables (nominal/ordinal), use Analyze → Descriptive Statistics → Frequencies instead — this gives you counts and percentages.

Reading the SPSS Output ▶
  • When you run any analysis, SPSS opens (or updates) the Output Viewer window
  • The Navigator panel on the left lists every output object (tables, charts) — click to jump directly to it
  • Double-click any table to enter pivot table editing mode — you can reformat cells, merge rows, and change fonts
  • Right-click any table for export options: copy as Rich Text, export to Word, Excel, or PDF
  • To export the full output: File → Export in the Output Viewer
Info

For reports, right-click tables and use "Copy Special → Rich Text" then paste directly into Word — it preserves all table formatting perfectly.

Common Gotchas ▶
  • String vs Numeric confusion — SPSS treats IDs stored as text differently from numbers. Go to Variable View and check the "Type" column. Change to Numeric if needed for calculations.
  • Missing value codes — never use 0 for "no response" unless 0 is a valid value. Common practice: use 99 or 999. Set this in Variable View under "Missing" so SPSS excludes them from calculations.
  • Decimal places in Variable View — the default is 2 decimal places. Whole-number variables (like age in years) should be set to 0 decimals to keep output clean.
  • Measure level matters — set variables to Scale (continuous), Ordinal, or Nominal correctly. Some procedures only accept Scale variables; others require Nominal.
  • Forgotten to save — SPSS does not auto-save. Save frequently with Ctrl+S, both the .sav data file and the .spv output file.
Chapter 03

Python Setup

Python is the world's most popular language for data analysis. This chapter gets you fully set up — from a blank machine to running your first analysis script — in under 20 minutes.

New to the Terminal? Start Here ▶

Every tool in this bootcamp — Python, R, Jupyter, Git — is controlled by typing commands in a terminal. If you've never used one, this 2-minute primer is all you need.

What is a terminal? — A text-based window where you type instructions instead of clicking buttons. On Windows, it's called Command Prompt (cmd) or PowerShell.

How to open it:

  • Press Win + R, type cmd, press Enter
  • OR search "Command Prompt" in the Start menu
  • OR in VS Code: press Ctrl+` to open the built-in terminal

Anatomy of a command:

python --version
↑        ↑
program  flag (option)

pip install pandas
↑      ↑       ↑
program action  package name

Essential commands:

CommandWhat it does
cd DesktopMove into the Desktop folder
cd ..Go back one folder
dirList files in current folder
clsClear the screen
↑ arrowRepeat last command
Tip

If a command fails, read the error message carefully — it usually tells you exactly what's wrong. Copy-paste the error into Google if you're stuck.

Don't panic: The terminal looks intimidating, but it's just a conversation. You type, the computer responds. That's it.

Step 1: Download Python

Go to python.org/downloads and click the large "Download Python 3.x" button. This will download the latest stable Windows installer.

Critical — Do Not Skip

On the first screen of the installer, check the box that says "Add Python to PATH" before clicking "Install Now". If you miss this step, Python will install but nothing will work in the terminal. You will need to uninstall and reinstall.

Step 2: Install VS Code

Go to code.visualstudio.com, download the Windows installer, and run it with all default settings.

After installation, open VS Code and install these two extensions from the Extensions sidebar (Ctrl+Shift+X):

  • Python — by Microsoft (enables code completion, linting, and running Python files)
  • Jupyter — by Microsoft (enables .ipynb notebook support inside VS Code)

Step 3: Verify Installation

Open Command Prompt: press Win+R, type cmd, press Enter. Then run:

python --version
pip --version

You should see something like Python 3.12.x and pip 24.x. If you see an error, go to the Troubleshooting section below.

Step 4: Install Required Packages

In the same Command Prompt window, run this single command to install everything you need for this bootcamp:

pip install pandas matplotlib seaborn jupyter streamlit

This will take 1–3 minutes depending on your internet speed. You'll see progress bars for each package. When it's done, you're ready.

Troubleshooting Python Installation ▶

Error: 'python' is not recognized

This means Python was installed without the PATH option. Uninstall Python from Windows Settings → Apps, then reinstall from python.org — this time, check "Add Python to PATH" on the first screen.

Error: 'pip' is not recognized

Try using the full Python module form instead:

python -m pip install pandas matplotlib seaborn jupyter streamlit

Windows Defender SmartScreen warning

If Windows blocks the installer with a blue "Windows protected your PC" screen, click "More info" and then "Run anyway". The Python and VS Code installers are safe — SmartScreen flags them simply because they're newly downloaded.

Packages install slowly or fail

Try switching to a different network or using a mobile hotspot. Some corporate or university networks block pip downloads. Alternatively, try adding --index-url https://pypi.org/simple/ to the install command.

Verification Script

Open VS Code, create a new file called verify.py, paste this code, and press F5 to run it:

import pandas as pd
print("pandas version:", pd.__version__)
print("Python is ready!")

If you see the pandas version number and "Python is ready!" printed in the terminal — you're set.

Chapter 04

R Setup

R is the preferred language for statistical computing and research-grade analysis. With the tidyverse package, R becomes one of the most powerful data tools available — and it's completely free.

Step 1: Download R

Go to cran.r-project.org and click "Download R for Windows" → "base" → click the latest version link at the top. Run the installer with all default settings.

Step 2: Download RStudio

R alone is powerful, but RStudio makes it usable. Go to posit.co/download/rstudio-desktop and download the free version for Windows. Install with all defaults.

Info

You need both R and RStudio. R is the engine; RStudio is the dashboard. Always install R first, then RStudio.

Step 3: Launch RStudio & Verify

Open RStudio (not R directly). You'll see 4 panes. The Console pane (bottom-left) shows the R version on startup — it should say something like R version 4.x.x. That confirms R is connected.

Step 4: Install the Tidyverse

In the Console pane, type this command and press Enter:

install.packages("tidyverse")

This installs the entire tidyverse suite — including ggplot2 (visualization), dplyr (data manipulation), readr (CSV import), and tidyr (reshaping data). Everything you need for this bootcamp comes in one command.

Installation takes 3–8 minutes. You'll see red progress text in the console — that's normal. Wait for the > prompt to return before proceeding.

Test Script

Once installation completes, run this test script in the RStudio console to confirm everything works:

library(tidyverse)
data <- read_csv("rwt_qlax_health_survey.csv")
summary(data)
ggplot(data, aes(x = age)) + geom_histogram(bins = 20)

This loads the tidyverse, reads the training dataset, prints a summary of all columns, and draws an age distribution histogram — your first R visualization.

Troubleshooting R Installation ▶

Package compilation errors (non-zero exit status)

Some tidyverse packages require build tools to compile from source. Install Rtools from:

cran.r-project.org/bin/windows/Rtools/

Download the version that matches your R version, install it, then restart RStudio and try install.packages("tidyverse") again.

Firewall blocking package downloads

If you're on a university or corporate network that blocks CRAN, try switching to a different mirror:

  1. In RStudio, go to Tools → Global Options → Packages
  2. Click "Change" next to the CRAN mirror
  3. Select a mirror in a different region (e.g., UK, US, or Australia)
  4. Click OK and retry the install

RStudio can't find R

This happens if R was installed after RStudio. Go to Tools → Global Options → General → R version and manually point RStudio to the R installation folder (usually C:\Program Files\R\R-4.x.x\).

Chapter 05

Jupyter Notebook

Jupyter Notebook is the standard environment for interactive data analysis with Python. Code, text, charts, and results all live in one document — perfect for exploratory analysis and presenting findings.

Install Jupyter

If you ran the full pip install command in Chapter 3, Jupyter is already installed. If you need to install it separately:

pip install jupyter

Launch Jupyter

Open Command Prompt, navigate to your working folder using cd, then run:

jupyter notebook

Your browser will open automatically at http://localhost:8888 showing the Jupyter file browser. If the browser doesn't open, copy the URL from the terminal and paste it into your browser manually.

Create Your First Notebook

  1. In the Jupyter file browser, navigate to your working folder
  2. Click the "New" button (top-right) and select "Python 3 (ipykernel)"
  3. A new notebook opens with one empty cell
  4. Click in the cell and type your first line of Python code
  5. Press Shift+Enter to run it and move to the next cell

Cell Types

Every Jupyter notebook is made of cells. There are two types you'll use:

  • Code cells — contain Python code. Press Shift+Enter to execute. Output appears directly below the cell.
  • Markdown cells — contain formatted text using Markdown syntax. Use these to add headings, explanations, and notes between code blocks. Press Shift+Enter to render.

Save & Export

Jupyter auto-saves every few minutes, but you can also press Ctrl+S at any time. To export your notebook:

  1. Go to File → Download as
  2. Choose HTML (.html) for a shareable, self-contained report
  3. Or choose PDF via LaTeX for a formatted PDF (requires LaTeX installed)

Chapter 06

Streamlit

Optional / Self-Study

Streamlit turns your Python data scripts into interactive web apps — no HTML, no CSS, no web framework knowledge required. From script to web app in 10 seconds.

Install Streamlit

Already done if you ran the full pip install in Chapter 3. Otherwise:

pip install streamlit

Run the Built-In Demo

Verify your installation and see what Streamlit can do by running:

streamlit hello
Tip

If streamlit is not recognized as a command, use the module form: python -m streamlit hello

This opens a browser window with interactive demos showing charts, maps, and data frames — all built with just Python.

Create Your First App

Create a new file called app.py in your working folder and paste this code:

import streamlit as st
import pandas as pd

df = pd.read_csv("rwt_qlax_health_survey.csv")

st.title("Health Survey Dashboard")
st.dataframe(df)
st.bar_chart(df['region'].value_counts())

Run Your App

In your terminal, from the same folder as app.py, run:

streamlit run app.py

Your browser opens automatically with a live, interactive dashboard showing your data table and a bar chart of survey regions. Any time you save app.py, Streamlit hot-reloads the app instantly.

Go Further

Full documentation, tutorials, and a component gallery are available at docs.streamlit.io. The gallery has hundreds of example apps built by the community.

Data Cleaning Challenge — 5 Issues to Find
