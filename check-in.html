Terminal 101

You'll need your terminal to verify tool installations. Follow these 4 steps to get comfortable.

Windows
macOS / Linux
Step 1 — Open your terminal
# Press Win + R, type "cmd", hit Enter
# Or search "Command Prompt" in Start Menu
Step 2 — Check where you are
C:\Users\You> cd
C:\Users\You
Step 3 — List files in this folder
C:\Users\You> dir
Desktop   Documents   Downloads   ...
Step 4 — Clear the screen
C:\Users\You> cls
Step 1 — Open your terminal
# macOS: Cmd + Space, type "Terminal", hit Enter
# Linux: Ctrl + Alt + T
Step 2 — Check where you are
$ pwd
/Users/you
Step 3 — List files in this folder
$ ls
Desktop   Documents   Downloads   ...
Step 4 — Clear the screen
$ clear
